# Reproducibility Summary

The starter notebook had several reproducibility problems. The data-loading step used a hardcoded path that only worked in the original author's environment, so I replaced it with a relative path and added instructions for placing the CSV alongside the notebook. There was no environment or dependency section, so I added one that imports and prints the exact package versions used, with install commands for anyone running outside Colab. Two operations, a small random sample and a bootstrap mean, used no random seed and produced different results on each run; I fixed this by setting a global random seed and passing it to both. The notebook also had no validation step, so I added checks for column names, row count, and outcome values, plus a check for biologically impossible zeros in Glucose, blood pressure, skin thickness, insulin, and BMI, which I then recoded as missing and filled using median imputation, a deterministic choice that keeps results stable across runs.

I also addressed the Data Science Director's notes: fixed the LaTeX formatting for the mean and standard deviation equations, added two bivariate visualizations and a correlation heatmap with justification for using Spearman correlation, added a Mann-Whitney U test as a second inferential method appropriate for BMI's skewed distribution, and replaced generic placeholder variable names in the machine-learning framing section with the dataset's actual variables.

I verified reproducibility by running the notebook from a clean kernel start to finish twice and confirming identical numeric results and figures both times.
